# Extension Icons

## Required Icons

The extension needs three icon sizes:
- `icon16.png` - 16x16 pixels (toolbar small)
- `icon48.png` - 48x48 pixels (extension management)
- `icon128.png` - 128x128 pixels (Chrome Web Store)

## Temporary Setup

Until you create custom icons, you can:

1. **Option 1**: Use emoji as icon (current)
   - Extension will work but show default icon

2. **Option 2**: Create simple icons
   - Use any image editor (Photoshop, Figma, GIMP, etc.)
   - Create 16x16, 48x48, 128x128 PNG images
   - Use a robot emoji 🤖 or AI-related graphic
   - Save them in this folder

3. **Option 3**: Generate online
   - Use https://favicon.io/ to generate favicons
   - Download and rename to icon16.png, icon48.png, icon128.png
